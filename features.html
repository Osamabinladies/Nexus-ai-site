FEATURES

NEXUSが、毎日を軽くする

4つのコア機能で、あなたの一日をそっとサポートします。

01

⏰
NEXUS · SCHEDULE MODE

SCHEDULE MODE

プランナー

SCHEDULE

スケジュール管理

予定を話しかけるだけで登録。重複や移動時間も自動で考慮します。

  • 音声・テキストで予定登録
  • 予定の衝突を自動検知
  • 前日・当日のリマインド通知
「明日の予定は、もう把握してます。」
🎙️ 音声で予定登録 ⚡ 衝突を自動検知 🔔 前日にリマインド

02

🏠
NEXUS · SMART HOME MODE

SMART HOME MODE

ガーディアン

SMART HOME

スマートホーム連携

照明・エアコン・鍵など、対応家電をひとつの会話でまとめて操作。

  • 主要スマート家電メーカーに対応
  • 「行ってきます」で一括オフ
  • 外出先からの遠隔操作
「『行ってきます』のひと言で、全部消します。」
🔌 主要メーカーに対応 🚪 外出先から遠隔操作 🌙 一括オフで安心

03

📝
NEXUS · NOTES MODE

NOTES MODE

スクライブ

NOTES

メモ・要約

会議や会話のメモを自動で整理し、要点だけをまとめて残します。

  • 音声メモの自動文字起こし
  • 長文の要約とタグ付け
  • 過去のメモをキーワード検索
「大事なところだけ、残しておきます。」
🗣️ 自動文字起こし 🏷️ 要約とタグ付け 🔍 キーワード検索

04

❤
NEXUS · WELLBEING MODE

WELLBEING MODE

コンパニオン

WELLBEING

健康サポート

生活リズムを見守り、無理のない範囲で軽いアドバイスを届けます。

  • 睡眠・活動リズムの記録
  • 水分補給や休憩のさりげない提案
  • 体調メモの簡易記録
「そろそろ、休憩しませんか？」
😴 睡眠リズムを記録 💧 水分補給を提案 📋 体調メモを簡易記録
